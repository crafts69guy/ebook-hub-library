# Ebook Hub Library

Freely licensed books for the [Ebook Hub](https://github.com/crafts69guy/ebooks)
Raycast extension. Every book here is public domain or Creative Commons, reviewed
through pull requests, and published through a generated `index.json`.

## How the Extension Uses This Repository

1. Ebook Hub reads `index.json` through jsDelivr:
   `https://cdn.jsdelivr.net/gh/crafts69guy/ebook-hub-library@main/index.json`.
2. When a reader adds a book, the extension downloads `book.json` and every
   chapter, and verifies each file against the SHA-256 digest in the index.
3. Books are stored locally in the reader's library and read offline.

## Layout

```text
books/<language>/<slug>/
  book.json          # metadata and chapter list
  chapters/0001.md   # one Markdown file per chapter
categories.json      # allowed category slugs
templates/book/      # starting point for new books
index.json           # generated by CI — never edit by hand
scripts/             # validation and index generation (Node.js 24, no dependencies)
```

## Continuous Integration

| Workflow | When | What |
| --- | --- | --- |
| **Validate** | Every pull request and push to `main` | Type-check, test with 95% coverage, validate all books, reject hand-edited `index.json` |
| **Publish index** | Push to `main` touching books, categories, scripts, or this workflow; manual dispatch | Regenerate `index.json`, commit it, purge the jsDelivr cache |

## Contributing

Read [CONTRIBUTING.md](CONTRIBUTING.md). The short version:

```fish
cp -r templates/book books/en/my-book
# edit books/en/my-book/book.json and chapters/
npm run validate
```

## Development

Requires Node.js 24 LTS (see `.nvmrc`).

```fish
npm install
npm run typecheck
npm test              # node:test with 95% coverage thresholds
npm run validate      # validate books only
npm run build-index   # validate and write index.json
```
